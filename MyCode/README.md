# 独立练习目录

这里保存通过力扣插件生成的 Python 3 解答，原有分类目录中的教学题解保持不变。

- 先独立思考和实现，再对照原有题解。
- 保留插件生成的题号与 `@lc` 标记，便于测试和提交。
- `Solution` 方法本身不会自动执行；用插件的 **Test / Submit** 运行力扣用例。
- 需要本地调试时，在文件底部用 `if __name__ == "__main__":` 添加调用，再运行当前文件或按 F5。
- 链表、二叉树等题目的本地运行需要自行提供 `ListNode` / `TreeNode` 定义和输入构造；力扣在线环境会提供它们。

不要把账号 Cookie、Token 或登录缓存保存到仓库。
